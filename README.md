ORION EARTH 14.1 — ВИПРАВЛЕННЯ PDF І ТАБЛИЦЬ

Що змінено:
1. Додано matplotlib до requirements.txt. Він містить Unicode-шрифт DejaVu Sans для українського PDF-звіту.
2. PDF-генератор спочатку шукає шрифт у пакеті matplotlib, потім у системних папках.
3. Якщо прямий PDF все одно недоступний, завантаж HTML-звіт, відкрий його у браузері й натисни «Зберегти як PDF / Друкувати» → «Зберегти як PDF».
4. Екосистемні сигнали показуються компактною таблицею; повні дані відкриваються в окремому розгортуваному блоці. CSV містить усі стовпці.
5. Наукові обчислення та пороги не змінено.
