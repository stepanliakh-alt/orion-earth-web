# ORION Earth Web 14.0 — Ecosystem Intelligence

**Доказовий кліматичний вебзастосунок для NASA Space Apps.** 12 відкритих розділів, темна тема, справжні дані з публічних API, порівняння регіонів, добові аномалії, екосистемні рекомендації та PDF-звіт.

## Найпростіше оновлення на GitHub

1. Відкрий репозиторій: https://github.com/stepanliakh-alt/orion-earth-web
2. Замінити в корені репозиторію **`app.py`** на файл із цієї папки. Через вебінтерфейс GitHub можна відкрити `app.py` → **Edit** (олівець), замінити вміст та натиснути **Commit changes**. Або видалити старий файл і завантажити новий **з точною назвою `app.py`** у корінь.
3. Замінити **`requirements.txt`** у корені (нова залежність `reportlab` потрібна для PDF).
4. Необов'язково: завантажити **`.streamlit/config.toml`** у таку саму папку в репозиторії. **Не** завантажувати `config.toml` просто в корінь.
5. Відкрити https://orion-earth-web.streamlit.app/ і зачекати на перезапуск. У разі помилки дивитися **Manage app → Logs**.

Локально: `pip install -r requirements.txt`, потім `streamlit run app.py`.

## Як показати менторам

1. У лівій панелі натисни **«⚡ Швидкий показ: Дрогобич ↔ Афіни»**. Застосунок отримує **справжні** добові NASA POWER 2010–2025, не вигадані значення.
2. Покажи **«Кожен день»**, **«Місяці та сезони»**, **«Порівняння регіонів»** та **«AI — аномалії»**.
3. Перейди до **«Географія території»**: натисни кнопки висот Copernicus та об'єктів OSM.
4. У **«Екосистемний вплив і звіт»** вибери ліс, луки, агроекосистему, болото або річку. За бажанням завантаж NDVI NASA MODIS і записи GBIF.
5. Покажи таблицю екологічних сигналів та натисни **«Завантажити екосистемний звіт — PDF»**.

**Важливо:** супутникові сервіси можуть відповідати повільно або тимчасово бути недоступними. Модулі не підміняють їхні дані симуляцією. Основний кліматичний аналіз NASA POWER працює незалежно від цих додаткових API.

## Джерела даних

| Дані | Джерело | Що саме отримуємо |
|---|---|---|
| Добова температура й опади | NASA POWER Daily Point API | PRECTOTCORR, T2M, T2M_MAX, T2M_MIN (UTC) |
| Висота рельєфу | Copernicus DEM GLO-90 через Open-Meteo | 9 справжніх значень висоти, локальний профіль |
| Теги земного покриву | © OpenStreetMap contributors через Overpass | Перелік тегованих об'єктів, **не** частка площі |
| Рослинність | NASA MODIS MOD13Q1 через ORNL DAAC TESViS | 16-денні літні NDVI-композити, з перевіркою pixel reliability за наявності |
| Записи видів | GBIF occurrence API | Записи у приблизному квадраті 10×10 км; **не** чисельність і **не** видове багатство |

Офіційні документи: [NASA POWER](https://power.larc.nasa.gov/docs/services/api/temporal/daily/), [NASA MODIS / ORNL DAAC](https://modis.ornl.gov/data/modis_webservice.html), [Open-Meteo Elevation](https://open-meteo.com/en/docs/elevation-api), [OpenStreetMap attribution](https://www.openstreetmap.org/copyright), [GBIF](https://www.gbif.org/).

## Що вже є

- 12 розділів на одній сторінці, навігація зверху та збоку, темна тема.
- Аналіз 1–5 точок, власні координати, швидка демонстрація.
- Добові, місячні, сезонні та багаторічні показники, просторові порівняння.
- Mann–Kendall, Theil–Sen, FDR, аналіз протилежних напрямів регіональних трендів.
- Isolation Forest: аномалії добових і річних показників, без тверджень про прогноз катастроф.
- Практична матриця дій для міської інфраструктури, агросектора та здоров'я.
- Нові модулі географічного паспорта, NDVI, GBIF, екосистемних рекомендацій.
- CSV, JSON, автономний HTML та екосистемний PDF.

## Межі доказовості

- NASA POWER — **сіткові продукти**, а не дані місцевої метеостанції. Координати не гарантують адресної точності.
- OpenStreetMap не дає повної автоматичної класифікації земного покриву; тип екосистеми **підтверджує користувач**.
- Дев'ять висот Copernicus не є деталізованою картою ерозії, підтоплень або зсувів.
- Короткий ряд NDVI не встановлює причинності чи довгострокового тренду.
- GBIF містить зміщення спостережень, тому кількість записів не є показником чисельності популяцій.
- FDR не виправляє часову автокореляцію; статистична значущість не дорівнює причинному зв'язку.
- Екосистемні рекомендації — **обґрунтовані напрямки польової перевірки**, а не офіційні попередження чи доведені збитки.
- Для незалежної валідації потрібні місцеві метеостанції, польові спостереження та гідрологічні/екологічні вимірювання.

## Перевірка коду

`python test_orion14.py` — перевіряє тренди, FDR, парсинг висот/OSM/GBIF/MODIS, PDF та екосистемні рекомендації **на тестових фікстурах**. Тестові дані ніколи не показуються користувачу застосунку. Для повної перевірки доступності сервісів потрібен інтернет і запуск Streamlit.

ORION Earth — незалежний дослідницький прототип; NASA не є розробником і не схвалювала його як систему попереджень.
