ORION EARTH WEB · NASA Climate Intelligence
Версія: 4.1 (публікаційна збірка, Streamlit web)
Мова інтерфейсу: українська
Джерело: NASA POWER Daily Point API
Статус: дослідницький прототип; NASA не розробляє та не схвалює застосунок.
Що робить застосунок
- Прямі запити до реального NASA POWER Daily API, без генерації демонстраційних кліматичних даних.
- Щоденна кількість опадів PRECTOTCORR, середня добова температура T2M, добові максимум та мінімум T2M_MAX / T2M_MIN.
- Відображення конкретних днів злив, сухих періодів (опади <1 мм), теплових епізодів (Tmax ≥30 °C) та їхніх дат.
- Окремий аналіз 12 місяців та 4 сезонів; порівняння до п'яти географічних точок за окремими NASA-запитами.
- Статистика: Kendall tau + Theil–Sen + FDR Benjamini–Hochberg для 14 річних індексів і окремо для груп місячних/сезонних порівнянь.
- Виявлення незвичайних днів та років алгоритмом Isolation Forest; це не прогноз катастроф.
- Інтерактивна карта, графіки Plotly, практичні інтерпретації, експорт CSV/JSON та автономний HTML-звіт з отриманих даних NASA.
- Темна тема, адаптована для демонстрацій.
- Панель фактичних відмінностей між першими та останніми п’ятьма повними роками для ключових індикаторів.
- Вибір будь-яких двох із 14 кліматичних показників для порівняння точок.
Публікація за одним посиланням (без .bat і локального Python)
1. Створи новий GitHub-репозиторій, наприклад orion-earth-web.
2. Завантаж у корінь репозиторію файли app.py, requirements.txt, README.md. Додай папку .streamlit з файлом config.toml. Не завантажуй nasa_cache/ або персональні дані.
3. Перейди до Streamlit Community Cloud, увійди через GitHub і обери Create app.
4. Вкажи репозиторій, гілку main, Main file path: app.py. У додаткових налаштуваннях обери Python 3.12.
5. Натисни Deploy. Після публікації матимеш адресу виду https://<назва>.streamlit.app — це і є посилання для менторів.
6. На сайті натисни «⚡ Швидкий показ: Дрогобич ↔ Афіни»: він здійснить живі запити NASA за 2010–2025 роки й побудує порівняння. Або обери власні координати й період.
7. У вкладці «Дані й методи» завантаж HTML-звіт — він працює офлайн після одержання даних NASA.
Важливо: жодна кліматична цифра не з'явиться, доки NASA не відповість або доки сервер не матиме копії раніше отриманої відповіді. Перший запит потребує доступу до NASA; якщо API недоступне, застосунок показує помилку, а не підставні дані. Вебсервер може перезапускатися, тому кеш на ньому не гарантовано постійний. Для презентації завчасно збережи HTML-звіт як резервний варіант.

Локальний запуск (необов'язково)
Python 3.12:
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
Streamlit відкриє адресу http://localhost:8501. Для публічного сайту локальний запуск не потрібний.
Методи й наукові обмеження
- NASA POWER Daily API — сіткові дані з характеристиками вихідних продуктів; це не вимірювання точкової наземної станції і не помісячні/річні середні, що завантажуються замість добових даних.
- Запити явно задають time-standard=UTC; період в інтерфейсі — повні календарні роки (до 2025 включно).
- -999 трактуємо як відсутнє значення; дні без спостережень не інтерполюємо. Для підсумків за місяць/рік/сезон необхідне покриття принаймні 90% днів.
- Сума опадів є сумою за відповідний період, сухі дні та дні спеки є підрахунком, температурний тренд може базуватися на річному середньому добової температури — це не підміна добових даних усередненням.
- Сухий день (<1 мм) не дорівнює посусі. Сильні опади (≥20 мм/день) не дорівнюють повені. Спека (Tmax ≥30 °C) не дорівнює індивідуальному ризику здоров'ю.
- Тренди — Kendall tau, нахил Сена й 95% ДІ; річні p-value скориговані FDR за родиною 14 показників. Часова автокореляція не скоригована, тому статистична значущість є попередньою.
- Isolation Forest — алгоритм пошуку незвичайних точок, не причинне пояснення чи прогноз.
- Розрахунки для різних точок сітки не означають, що доведено статистично значущі відмінності цілих країн.
- Практичні інтерпретації — дослідницькі сигнали; не є системою оперативного оповіщення або прогнозом збитків.
- Код перевіряє структуру відповідей NASA, пропущені дні та зберігає URL запиту, час отримання й SHA-256 відповіді в кеші. SHA-256 перевіряє цілісність локальної копії, а не є незалежною сертифікацією NASA.
Тестування
python tests/test_core.py
Тестовий модуль використовує лише штучні дані для перевірки математичних функцій; у застосунку вони ніколи не відображаються. Тести не підміняють перевірку живого API або повний браузерний тест Streamlit.
